# 直播弹幕助手 · 使用说明

> Electron 桌面应用：挂载各平台网页端直播间 → 捕获弹幕 → 智谱 GLM 生成回复 → 自动发回直播间。

## 快速开始

```bash
npm run dev        # 开发模式（正常 GPU）
npm run dev:nogpu  # 无 GPU 环境
npm run build      # 构建
npm run dist       # 打包 NSIS 安装包
```

## 支持的平台

| 平台 | 弹幕抓取 | 发送 | 登录方式 |
|---|---|---|---|
| B站 | ✅ 主进程直连 | ✅ 登录后 | 应用内扫码 / Cookie 导入 / 登录窗口 |
| 抖音 | ✅ CDP 抓帧 | ✅ 登录后 | 登录窗口（主站点「登录」） / Cookie 导入 |
| 斗鱼 | ✅ CDP 抓帧 | ✅ 登录后 | 应用内扫码 / Cookie 导入 / 登录窗口 |
| 虎牙 | ✅ DOM 兜底 | ✅ 登录后 | 登录窗口（账密/微信/QQ） / Cookie 导入 |
| 快手 | ✅ 页面注入 | ✅ 登录后 | 应用内扫码 / Cookie 导入 / 登录窗口 |

> 抓取弹幕不需要登录；**发送**弹幕必须登录对应平台账号。
> 快手/抖音/虎牙的弹幕区在游客态可能不渲染，登录后即正常。

## 账号管理

顶栏**左上**切换平台 → 点 **「👤 账号信息」**：

- **扫码登录**：B站/快手/斗鱼在应用内直接生成官方二维码（快手二维码约 1 分钟自动刷新）；
  抖音/虎牙打开平台官方登录窗口（窗口内扫码或账密均可），登录成功自动保存 Cookie
- **Cookie 导入**：浏览器登录平台官网 → F12 → Application → Cookies → 复制关键项粘贴导入
  （应用会校验关键登录 Cookie，缺了会明确提示）
- **多账号**：同平台可保存多个账号，一键切换 / 删除 / 退出（退出保留记录，可随时切回）
- Cookie 持久化在 `platform-accounts.json`，重启不丢

## 直播画面

添加房间后自动把网页端播放器搬进画面区（不拉流，零额外带宽）：
- 可拖下边缘调整高度，双击复位
- 「纯视频模式」自动隐藏页面其它元素，只留播放器与弹幕输入框
- 音频：只有当前展示的房间出声

## AI 回复

- 触发模式：智能 / 全部 / 仅提问 / 关键词 / 随机（设置里配置）
- 防风控：8~25 秒随机延迟、限频、熔断、敏感词去重、人工确认面板

## 数据留存与导出

- 所有弹幕自动写入本地 SQLite（`danmaku.db`），无需手动开启
- 「历史」面板可按房间/关键词查询，点 **导出 CSV / 导出 JSON** 保存全部匹配记录
  （CSV 带 UTF-8 BOM，Excel 直接打开不乱码）

## 常见问题

- **收得到弹幕但发不出（B站）**：缺少 `bili_jct` —— 账号信息面板会显示警告，重新扫码即可补齐
- **虎牙房间打开后显示错误页**：进房会自动「清 Cookie → 访首页 → 进房间」三步处理；
  若仍失败，在账号面板登录虎牙后重试
- **快手二维码很快过期**：正常（官方限制约 1 分钟），应用会自动刷新
- **换启动方式后变成未登录**：userData 已钉死为 `live-danmaku-assistant`，若仍异常检查
  `%APPDATA%/live-danmaku-assistant/Network/Cookies`
